# EXTENSION_PLAN — Empfohlene Cursor/VS Code Extensions

Ziel: **stabilere Navigation im Code**, bessere **Fehler-Sichtbarkeit** und weniger Reibung bei Flutter + Supabase + Markdown-Doku.

## Pflicht
- **Dart**: Syntax, IntelliSense, Analyzer-Integration, Debugging für Dart-Code.
- **Flutter**: Flutter-spezifische Tools (Run/Debug, Widget-Inspektion, Projektstruktur).

## Sinnvoll (empfohlen)
- **GitLens**: Kontext zu Änderungen/Blame/History direkt im Editor (hilft bei minimalinvasiven Fixes).
- **Error Lens**: Fehler/Warnungen inline sichtbar — reduziert „Übersehen“ von Analyzer-Issues.
- **Even Better TOML**: Für TOML-Dateien, falls Tools/Configs dazukommen (lesbarer, weniger Tippfehler).
- **YAML**: Pubspec/Supabase/CI-Konfigurationen sicher bearbeiten.
- **Markdown All in One**: Saubere Pflege von `AGENTS.md` und `docs/ai/*` (TOC, Formatierung, Shortcuts).

## Optional (je nach Arbeitsweise)
- **REST Client**: Edge-Functions/HTTP-Endpunkte direkt aus dem Editor testen (ohne Postman).
- **SQLTools**: Komfortabler Zugriff auf SQL (nützlich bei Supabase/DB-Arbeit; nur wenn verwendet).
- **Path Intellisense**: Schnellere, fehlerärmere Pfad-/Import-Auswahl in größeren Repos.
